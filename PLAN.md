# План: Doom-рация

## Тема демо

**Shareware Doom в окне + LLM-напарник по рации.** Зрителю сразу видно: игра слева, Infereco справа подсказывает куда идти и вбивает читы в эмулятор. Самоулучшение: «застрял в яде» > критик пишет факт > следующая рация уже гонит к краю пола.

## Стек

| Слой | Выбор | Зачем |
| --- | --- | --- |
| Язык | Java 25 LTS | последняя LTS |
| Фреймворк | Spring Boot 4.1.0 + Spring Framework 7 | Boot 7 не существует |
| AI | Spring AI 2.0 `ChatClient` | OpenAI-compatible Infereco |
| Чат / рация | `deepseek/deepseek-v4-flash-dspark` | быстро, коротко |
| Критик | `glm-5.2` | оценка и новый факт |
| RAG | lexical retrieve + learned facts | маршрут E1M1, читы, тактика |
| Голос | локальный Vosk | без Google Speech |
| Игра | js-dos + shareware doom.jsdos | Doom в том же окне |

## Этап 1 (сейчас)

После каждого хода игрока в рацию:

1. Достаём seed (Hangar, читы, тактика) + выученные факты.
2. DeepSeek отвечает.
3. GLM ставит `quality`, может записать факт.
4. Авторация каждые ~9 с знает сколько секунд прошло и какой чит уже вбивали.
5. Кнопки читов и фраза модели печатают код в DOSBox через `sendKeyEvent`.

## Этап 2 (следующий)

Техподдержка репозитория и саморазвёртывание из чата. Заготовка: `src/main/resources/support/project.md`.
