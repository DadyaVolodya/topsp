# Технологии напарника (черновик доклада)

Живой список того, что реально крутится в демо. Не теория, а слой за слоем.

## Как это похоже на Harness

Cursor Harness: скил выбирается по задаче, субагент делает узкую работу, MCP даёт инструменты окружения.

Здесь то же самое, только внутри Spring-приложения:

| Harness | У нас |
| --- | --- |
| Skill | markdown в `src/main/resources/skills/` |
| Router | `SkillRouter` по эфиру и кадру: interview / pto-site / doom |
| Subagent | чат MiniMax, зрение gpt-5.4-mini, критик GLM, рация GLM |
| MCP tools | микрофон+Vosk, захват экрана, RAG, API ПТО (suggest/search), читы js-dos |

Три скила и всё. Главный инструмент: кадр экрана плюс эфир.

## Стек

- Java 25 LTS, виртуальные потоки
- Spring Boot 4.1, Spring Framework 7
- Spring AI 2 OpenAI-compatible клиент на Infereco
- MiniMax-M2.7 чат, glm-5.2 критик и быстрые подсказки, openai/gpt-5.4-mini зрение
- Vosk small-ru-0.22, PCM 16 kHz, WebSocket `/ws/stt`
- AudioWorklet: линейный ресемпл, high-pass, AGC
- getUserMedia без echoCancellation, чтобы не глушить собеседующего из колонок
- getDisplayMedia со звуком вкладки (Meet/Zoom в Chrome)
- js-dos + shareware Doom
- lexical RAG по markdown + выученные факты GLM

## Эфир собеседующего

Почему раньше плохо слышал: echoCancellation вырезал голос из колонок, а звук вкладки встречи не брался вообще.

Сейчас два входа в один микшер: микрофон комнаты и audio tracks вкладки. Для собеседующего в наушниках обязательно шарить вкладку Meet/Zoom и включить «звук вкладки». Нативное окно Zoom на macOS звук часто не отдаёт.

Vosk выбирает из 5 гипотез, лексикон подтягивает слова встречи и ПТО.

## Экран

JPEG ~1440px, vision-модель видит кадр, роутер переключает скил. Для ПТО напарник дергает те же запросы, что и фронт: `POST /api/pto/institutions/search` и `GET /api/pto/institutions/suggest`, открывает карточку `/institutions/{id}` и Яндекс `rtext`. Плейбук знает клики: поле «Поиск по названию», подсказка, «Маршрут». «Рисунок и живопись» только если просили это направление.

Логин стенда в `config/application-local.yml`, в git не кладётся.

## Что объяснить на докладе

1. Почему захват экрана это не «скриншот», а петля: кадр > скил > один следующий клик.
2. Почему STT и AEC враги, если цель слышать собеседующего.
3. Почему скилы лучше одной гигантской system prompt: роутер режет контекст под сцену.
4. Почему Doom спрятан: тот же harness, другой скил и другой набор tools.
