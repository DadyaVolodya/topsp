# Почему TopSP круче «просто чата с LLM»

Большинство AI-продуктов для разработки - это обёртка над моделью: закинули кусок текста, получили красивый ответ. TopSP - **исполняемый контур** вокруг требования, кода и продукта. Модель здесь не «мозг всего», а один из узлов пайплайна.

---

## 1. Требование - гражданин первого класса

СП не «прикрепили к промпту». Её:

- парсят на секции;
- версионируют (`v1` > `v2`);
- диффят семантически (запрещено/можно, high/critical), а не строкой;
- защищают эвристикой от «занижения» LLM (policy-смены не становятся cosmetic).

Итог: изменение в постановке - **событие системы**, не тема для болтовни.

## 2. Код в том же контуре, что и СП

Индекс `petclinic-front` / `petclinic-back` режет исходники на символы и кладёт в knowledge (`source=code`). Impact ищет `VisitService.canCancel`, `VisitRow`, а не «какой-то backend».

Без кода AI гадает. С кодом - связка **было/стало > файл > символ > задача**.

## 3. Детерминизм + LLM, а не LLM вместо инженерии

Порядок жёсткий:

1. парсинг и hash секций;
2. эвристический significance;
3. LLM только уточняет формулировки (и не имеет права молча откатить policy);
4. поиск по индексу кода;
5. draft задач front/back;
6. notice в Telegram текстом «тема / описание».

Это не «магия модели». Это **pipeline с измеримыми шагами** (`specDiffDurationMs`, `impactAnalysisDurationMs`, `taskGenerationDurationMs`).

## 4. Продуктовая карта в каждом промпте

`PRODUCT CARD` держит LLM внутри PetClinic. Нет расползания в чужой домен. Режимы разделены: TopSP / hint / interview / doom - разный skill, разный контекст, не один помойный system prompt на всё.

## 5. Самообучение без театра

Фоновый learn-loop + критик:

- задаёт вопрос по СП/коду;
- оценивает ответ (`quality` 0-10);
- при `keep=true` кладёт факт в KB (`source=learned`).

Метрики живые: ходы, циклы критика, KB, avg latency. Это не слайд «мы используем AI» - это **замкнутый контур улучшения на своём же продуктовом контексте**.

## 6. Живучесть LLM-слоя

Primary: Infereco. Fallback: Ollama Cloud (бесплатный ключ) / локальный Ollama. Таймаут Infereco не убивает демо - контур продолжает работать.

## 7. Канал до команды, не только до чата

Изменение СП уходит в Telegram подписантам: summary + карточки задач. Разработчик получает действие в привычном канале, а не «посмотри ответ в боте чата».

## 8. Что меряем - то и продаём

`GET /api/metrics` отдаёт не vanity:

- диалог: `turns`, `avgLatencyMs`, `lastQuality`;
- пайплайн: длительности diff / impact / task;
- результат: `changesDetected`, `affectedFiles`, `tasksGenerated`;
- обучение: `improvementCycles`, `knowledgeDocs`.

Конкуренты показывают «вот что сказал GPT». Мы показываем **сколько изменений поймали, сколько файлов задели, сколько задач собрали, сколько фактов выучили**.

---

## Одним абзацем для слайда

TopSP - не чатбот по репозиторию. Это runtime-слой продукта: версия СП, semantic diff, индекс кода, impact, задачи, Telegram, метрики и самокритика. LLM ускоряет понимание, но **истина живёт в пайплайне** - поэтому ответ воспроизводим, измерим и привязан к front/back символам, а не к удачной галлюцинации.
